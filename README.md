# DeepTrace

**DeepTrace** is a text analysis tool that combines AI-generated text estimation with semantic similarity-based plagiarism screening.

It uses a pretrained RoBERTa classifier to estimate whether submitted text may be AI-generated, and Sentence Transformers with FAISS to identify potentially similar passages from reference webpages supplied by the user.

## Features

- **AI-text estimation:** Uses a pretrained RoBERTa sequence classifier to estimate the probability that text is AI-generated.
- **Semantic similarity search:** Uses `all-MiniLM-L6-v2` to generate sentence embeddings.
- **FAISS indexing:** Efficiently searches reference passages using vector similarity.
- **Webpage extraction:** Fetches and extracts text from user-provided URLs.
- **Passage-level matching:** Flags submitted passages that exceed a configurable similarity threshold.
- **Streamlit interface:** Provides a simple interface for submitting text and reviewing results.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Krish1kaa/DeepTrace.git
cd DeepTrace
```



### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

### 4. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```

The application will be available at the local URL displayed in your terminal.

The first run downloads the required pretrained models from Hugging Face.

## Usage

1. Enter the text you want to analyze.
2. Optionally provide reference webpage URLs, one per line.
3. Adjust the similarity threshold if needed.
4. Click **Analyze**.
5. Review the AI-generated probability estimate and any flagged matching passages.

AI-text estimation works without reference URLs. Similarity-based screening requires reference webpages.

## Tests

Run the test suite from the project root:

```bash
python -m pytest -v
```

## Configuration

The default AI detector can be changed using the `DEEPTRACE_DETECTOR_MODEL` environment variable.

**PowerShell:**

```powershell
$env:DEEPTRACE_DETECTOR_MODEL = "path/to/your/checkpoint"
streamlit run app.py
```

The custom classifier must use compatible `Fake` and `Real` labels, or the scoring logic in `deeptrace/detector.py` must be adapted.

## Limitations

- The default AI detector, `openai-community/roberta-base-openai-detector`, was trained to distinguish GPT-2-generated text from human-written text. Its predictions are not reliable proof of authorship, particularly for short passages or text generated by newer language models.
- The detector uses the first 512 tokens of the submitted text.
- Semantic similarity can identify related or paraphrased passages, but similarity alone does not establish plagiarism.
- Matching is limited to the reference URLs supplied by the user. DeepTrace does not search the entire internet.
- Webpage extraction depends on page accessibility and structure. Some websites may block requests or return incomplete content.
- Similarity results depend on the selected threshold and embedding model.

**Important:** DeepTrace is an experimental screening tool. Its results should be interpreted as indicators for further review, not definitive academic or authorship judgments.
